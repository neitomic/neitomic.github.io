Following up after my [markdown preview server](my-markdown-preview), it worked for awhile until I started going fully agentic, with few agents working on different things at the same time.

I started not looking into the code anymore, and work mostly on documentations. My workflow became, asking an agent to plan for works, then review the plan document, ask agents to update the design/plan, then hand it over to agent to work on it. 

With this, sitting at front of the computer screen, just to watch the agents, is not the case anymore. Now I can go off for a walk and think, or do something else. So, I think I would need some place that the agent can share documents with me, and I can read it easily.

So here come [gist](https://github.com/neitomic/gist). It is a simple inbox that allowed agents to drop a markdown or html page, then I can easily read on phone. And it helped me a lot. Of course, I need to have a way to remotely communicate with agents. I currently using Rex from Superlogical, but many harnesses are supporting remote control.
